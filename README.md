# Proyecto Urban Grocers - Automatización de Kits

## Descripción del Proyecto
Este proyecto automatiza las pruebas de API para la creación de kits de productos en la aplicación Urban Grocers, enfocándose en la validación de las reglas del campo `name`.

## Fuente de Documentación Utilizada
* **apiDoc**: Documentación oficial de los endpoints de la API de Urban Grocers.

## Tecnologías y Técnicas Utilizadas
* **Python**: Lenguaje de programación principal.
* **Pytest**: Framework para la ejecución de las pruebas automatizadas.
* **Requests**: Librería para realizar peticiones HTTP (GET, POST, PUT, DELETE).
* **Git y GitHub**: Control de versiones y almacenamiento del repositorio.
